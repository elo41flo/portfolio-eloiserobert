2-2 Bestiaire d'outils

Les outils que j'invoque pour auditer la performance, l'accessibilité et l'empreinte d'un site.

🚦

Lighthouse

Performance

Outil de Google pour mesurer la performance, l'accessibilité et les bonnes pratiques SEO d'une page web.

🌊

WAVE

Accessibilité

Outil d'évaluation de l'accessibilité web permettant d'identifier les erreurs de contraste et de structure (RGAA).

⏱️

Core Web Vitals

UX / Vitesse

Indicateurs clés de Google (LCP, INP, CLS) mesurant l'expérience utilisateur réelle : chargement, réactivité et stabilité.

🌱

EcoIndex

Éco-conception

Mesure de l'empreinte et de la performance environnementale d'une page web.
